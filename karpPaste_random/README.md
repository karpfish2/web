# karpPaste_random

Простой веб-сайт для создания и просмотра случайных текстовых паст, оптимизированный для сети Tor.

## Функциональность

- Создание новых паст (максимум 5000 символов)
- Просмотр случайных паст без повторений
- Сброс истории просмотров
- Адаптивный дизайн с желтой темой
- Анимации и современный интерфейс
- Оптимизация для сети Tor

## Установка

1. Убедитесь, что у вас установлен Python 3.7 или выше
2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # для Linux/Mac
   # или
   .\venv\Scripts\activate  # для Windows
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск с Tor

1. Установите и настройте Tor:
   ```bash
   sudo pacman -S tor
   sudo systemctl start tor
   ```

2. Настройте Tor для работы с вашим приложением:
   ```bash
   sudo nano /etc/tor/torrc
   ```
   Добавьте следующие строки:
   ```
   HiddenServiceDir /var/lib/tor/karpPaste_random
   HiddenServicePort 80 127.0.0.1:5000
   ```

3. Перезапустите Tor:
   ```bash
   sudo systemctl restart tor
   ```

4. Получите ваш .onion адрес:
   ```bash
   sudo cat /var/lib/tor/karpPaste_random/hostname
   ```

5. Запустите приложение:
   ```bash
   python run.py
   ```

## Безопасность

- Все соединения защищены через Tor
- Включены строгие заголовки безопасности
- Отключены внешние зависимости
- Используются системные шрифты
- Реализовано ограничение скорости для предотвращения спама
- Данные пользователей не сохраняются без необходимости

## Использование

1. Введите текст в поле ввода и нажмите "Сохранить"
2. Нажмите "Показать случайную пасту" для просмотра случайной пасты
3. Нажмите "Сбросить историю" для очистки истории просмотров

## Технические детали

- Backend: Flask + SQLAlchemy
- База данных: SQLite
- Frontend: HTML, CSS, JavaScript
- Хранение истории просмотров: localStorage
- Оптимизация для Tor: отключены внешние зависимости, системные шрифты, строгие заголовки безопасности
